# nichoojogo
Conceito do jogo: dado uma pergunta tema, escolher uma palavra que esteja de acordo. O mais nichado e pouco usual que é a palavra, mais pontos você ganha. Objetivo: acumular o máximo de pontos em uma sessão que é diariamente remontada com perguntas inéditas. Compartilhar seus resultados com seus amigos. Design: 2d, sprites pixelados, chamativo.
